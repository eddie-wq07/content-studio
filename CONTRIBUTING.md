# Contributing

Run `npm start`, make a focused change, then run `npm run check`, `npm test`, and `npm run build`.

Keep the local-first promise: no uploaded account data, analytics telemetry, committed access tokens, private exports, or filesystem access. Use made-up fixtures and label them. New providers should return the validated workspace schema. Explain missing API metrics instead of inventing values. Keep copy readable to creators with basic stats knowledge and keep charts keyboard accessible.

Open a GitHub issue describing the change, or submit a pull request with its behavior and validation. Never include private exports or credentials in issues.
